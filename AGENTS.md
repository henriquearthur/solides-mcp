# solides-mcp

Servidor MCP para a API Sólides. A especificação OpenAPI está em `docs/api/openapi.json`.

## Agent skills

### Issue tracker

Issues são rastreadas no GitHub Issues de `henriquearthur/solides-mcp`, via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Usa as cinco labels padrão: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: um `GLOSSARY.md` e `docs/adr/` na raiz. See `docs/agents/domain.md`.
